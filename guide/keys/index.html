Keyboard map

Essential defaults — customize in Options

Defaults can change with your Custom key mappings. Use side panel → Keys as the live truth for the current tab.

Scrolling & page

KeysAction
j k h lDown / up / left / right
d uHalf page down / up
gg GTop / bottom
rReload
yyOften copy URL (check maps)

Links & navigation

KeysAction
fLink hints — current tab
FLink hints — new tab
H LHistory back / forward (common maps)
[[ ]]Previous / next page heuristics

Tabs & UI

KeysAction
o OOmnibar current / new tab
b BBookmarks modes (if mapped)
TTab switcher / related
x XClose / restore
tNew tab (mapped command)
gSSide panel
gAWindows omnibar
?Help
:Command palette entry

Find, visual, insert

KeysAction
/Find
n NNext / previous find
vVisual
iInsert

Window docking (common)

KeysAction
Alt+arrowsDock to edges (if mapped / OS allows)
Palette :winDock, maximize, center, cycle

Customizing safely

  1. Export or screenshot current maps
  2. Change one binding
  3. Save Options and hard-reload a test page
  4. Prefer unmap then map over silent overrides you forget
