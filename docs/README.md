## In-extension wiki

Users of an installed build should prefer the **in-extension wiki**:

- Side panel → **Wiki**
- Options → wiki links in help text
- Omnibar → `:wiki`
- File: `pages/wiki.html` · content: `pages/wiki-content.ts`

The wiki is the product handbook (including permissions and developer theory). This `docs/` folder mirrors and expands that material for GitHub and store submission.
