Excluded URLs and keys
Patterns Keys
Wholly or partially disable Vim+. A "Pattern" is a JS regular expression if it starts with "^", or ":" + the header of a URL, or "`" + URLPattern (a way to match URLs in W3C spec.). Otherwise it will be converted.
If "Keys" is empty, Vim+ gets wholly disabled;
if "Keys" starts with "^", only listed keys are enabled,
and all others are passed through;
otherwise, just the listed keys are passed through.

Hashbangs (omnibar)
Omnibar: !g cats, !grok …, !gpt …. Delete all and save to restore defaults (includes AI engines). Wiki: Hashbangs

Omnibar shortcuts — same format as search engines.

Do not start a line with ! (comment). Put a plain alias first:

g|!g|google: https://www.google.com/search?q=%s Google
grok|!grok: https://grok.com/?q=%s Grok

Type !g cats in the omnibar. First keyword wins; save to apply.
Custom search engines
Delete all to reset this option.

Define search engines to build URLs. Format:

a|A|MainName: https://a.com/?q=%s
js\:|JS: javascript:\ $S; Run JavaScript
key: https://c.com/$s/space=\s\ space_end
# comment

$s will be replaced with real queries.

Reading & View
Uncheck to hide the bar globally. Per-tab toggle: omnibar :prog. Wiki
Appended after built-in rules. Selectors: #vp-read-progress-track, #vp-read-progress-fill, #vp-read-infinity.

On by default for every normal webpage. Gray track + red fill grows left→right as you scroll.

Color / height change the built-in look; CSS box lets you restyle the bar fully.

:prog toggles for the current tab. Reader View :read, highlighter :hl, and view tools live under the : palette.
:view color profiles
Overrides CSS for palette :gray :blue :inv :sepia :blur :hicon :dim :focus. Format: name: css per line. Empty = built-ins (sane defaults). Insert built-in profiles · Wiki: :view FX

These are page filters, not Vim+ chrome. jumble scrambles text in JS and cannot be restyled here.

After Save, toggle the command again on a tab to apply the new CSS.

Vomnibar settings
Delete all to reset this option.
Adjust some inner behaviors of Vomnibar:
"maxMatches" should be in 3 ~ 25 ;
"queryInterval" should be in 0 ~ 1200 (unit: ms) ;
"size" is to calculate Vomnibar's height;
"styles" may be "dark" & "mono-url" & "time" & "absolute-time".
"actions" may be "opener" & "icase".
A low queryInterval will cause CPU cost a bit higher.
Auto substitution of various text
Substitute text before doing real actions, when copying / pasting through Vim+'s commands.
Support a simpler version of syntax of the "sed" tool.
The prefix character may be c|p|s|i|g …; "c" means copying, "p" for pasting and "s" for both. Auto resize.

Ignore list of history titles
Usually Vomnibar follows title changes in browsing history. However, if you do want to ignore some changed titles, you may add RegExp lines here.
One piece per line; no trimming; case-sensitive; "#" at the beginning means comments. Auto resize.
Block list of words for Vomnibar
For a bookmark / history item, if its title or URL contains any word or phrase in this list, it will not be listed on Vomnibar or the browser omnibox.
One piece per line; no trimming; case-sensitive; "#" at the beginning means comments. Auto resize.
