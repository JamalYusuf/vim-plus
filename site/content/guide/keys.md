Defaults can change with your **Custom key mappings**. Use side panel → **Keys** as the live truth for the current tab.

## Scrolling & page

| Keys | Action |
|------|--------|
| `j` `k` `h` `l` | Down / up / left / right |
| `d` `u` | Half page down / up |
| `gg` `G` | Top / bottom |
| `r` | Reload |
| `yy` | Often copy URL (check maps) |

## Links & navigation

| Keys | Action |
|------|--------|
| `f` | Link hints — current tab |
| `F` | Link hints — new tab |
| `H` `L` | History back / forward (common maps) |
| `[[` `]]` | Previous / next page heuristics |

## Tabs & UI

| Keys | Action |
|------|--------|
| `o` `O` | Omnibar current / new tab |
| `b` `B` | Bookmarks modes (if mapped) |
| `T` | Tab switcher / related |
| `x` `X` | Close / restore |
| `t` | New tab (mapped command) |
| `gS` | Side panel |
| `gA` | Windows omnibar |
| `?` | Help |
| `:` | Command palette entry |

## Find, visual, insert

| Keys | Action |
|------|--------|
| `/` | Find |
| `n` `N` | Next / previous find |
| `v` | Visual |
| `i` | Insert |
| `Esc` | Exit / cancel |

## Window docking (common)

| Keys | Action |
|------|--------|
| `Alt`+arrows | Dock to edges (if mapped / OS allows) |
| Palette `:win` | Dock, maximize, center, cycle |

## Customizing safely

1. Export or screenshot current maps  
2. Change **one** binding  
3. Save Options and hard-reload a test page  
4. Prefer `unmap` then `map` over silent overrides you forget  

Deep dive: [Key mappings](/docs/key-mappings/) and the in-extension wiki **Key mappings**.
