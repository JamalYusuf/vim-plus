Mouse browsing is precise. It is also a constant context switch. Vim+ keeps the everyday browser loop — navigate, open, search, command, arrange — on the home row.

The problem

Browsers were designed for the mouse. Your work was not.

Knowledge work is a rhythm of find → open → read → act → switch. Every time you reach for the mouse to click a link, hit the back button, hunt a tab, or drag a window, you break that rhythm. The cost of each interruption is tiny. The sum, across a day of research, debugging, reading RFCs, and reviewing PRs, is not.

Without Vim+

  • Locate cursor → aim → click → re-home hands
  • Tab bar hunting across 40 tabs
  • Address bar for every search
  • Buried menus for “close others”, mute, dock
  • Help scattered across dead wiki links

With Vim+

  • f labels every link — type two keys to open
  • o omnibar ranks history, tabs, bookmarks
  • : palette for power actions by name
  • Side panel command center when pages block keys
  • In-extension wiki that ships with the build

Theory

Modal control is a feature, not nostalgia.

Vim+ borrows ideas that editors got right decades ago: modes, counts, and composable commands. It is not “Vim inside Chrome.” It is a browser control plane that stays out of your way until you need it — then gets out of the way again with Esc.

Normal mode is the default

Keys are commands: scroll, hint, open, search. You are navigating, not typing into the page. Focus an input (or press i) and you enter insert — the page gets the keys again.

Hints beat aim

Link hints turn every clickable into a short label. Your eyes already found the target; your fingers finish the job. No pixel-perfect pointing across a 4K display.

Commands are the API

Key maps are convenience. The stable surface is the command: run it from a key, the : palette, or the side panel. Discover first, bind later.

Escape always works

Partial chords, find mode, hints, omnibar — cancel with Esc. Predictable exit is what makes modal UIs safe for daily use.

If you already live in Vim, tmux, or a tiling WM, this will feel like finishing the stack. If you don’t: start with five keys (j k f o Esc) and grow only what pays rent.

What it does

A control plane for the whole browser loop

Not a single trick. A coherent set of tools for moving through the web at the speed of thought.

f F

Link hints

Open, new tab, copy, hover, download. Labels appear; type to activate. The classic keyboard browsing superpower, refined.

o O

Omnibar

History, domains, bookmarks, open tabs, windows. Hashbangs for search and AI prompt send (!g, !grok, !gpt…).

:

Command palette

Privacy tools, tab ops, window dock, reader, highlighter, zen mode, clipboard helpers — searchable short names.

gS

Command center

Side panel for keys, commands, tabs, closed sessions, Reading List. Works when content scripts can’t (chrome://, etc.).

jk/v

Navigate & select

Scroll, find, visual selection, marks, frames. Counts work: 5j, not five presses if you don’t want them.

:read

Reading tools

Progress bar by default, Mozilla Readability reader view, highlighter with comments, focus FX, zen window.

:win

Windows & tabs

Dock to edges, maximize, center, cycle windows. Pin, mute, discard, restore closed, tab groups — via keys or palette.

map

Yours, remapped

Full map language, site-specific maps, exclusions, user CSS, hashbang engines. Start stock; shape it to your hands.

Why you should want it

Not faster for screenshots. Faster for real days.

  1. You keep flow while reading technical material. Scroll and jump links without breaking eye-hand coupling. Progress bar shows how deep you are in a long post.
  2. You stop treating the tab bar as a UI. Omnibar and side panel find the tab by content. Closed-session restore is a command, not archaeology.
  3. Power features become discoverable. The palette and command center surface dock, shred, reader, and clipboard tools without a 200-line cheat sheet day one.
  4. Restricted pages don’t brick you. When Chrome blocks content scripts, the side panel and global shortcuts still reach the extension.
  5. Help doesn’t rot. The wiki ships inside the extension. This site is the public mirror — not a dependency for day-to-day use.
  6. Privacy defaults match how engineers think. Local settings, opt-in sync, user-initiated history tools. AI hashbangs open the vendor’s site with your prompt — Vim+ does not proxy your queries through a custom backend.

A day in the loop

What “keyboard-first” actually looks like

o

Jump somewhere

Open omnibar, type a fragment of a URL or title, Enter. Or !gh vim-plus / !grok explain ….

f

Follow the interesting link

Hints paint the page. Two keystrokes. New tab with F if you want to keep your place.

j k

Read

Scroll on the home row. /find when scanning. :read when the page is a wall of chrome.

:

Act

Copy markdown link, dock the window, mute the noisy tab, shred a domain you regret opening — without a menu tour.

gS

Command center

When you need a map of everything bound, or Chrome’s own pages won’t accept keys — open the side panel.
